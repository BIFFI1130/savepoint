プライバシーポリシー

最終更新日: 2026年10月14日

BIFFI（以下「当方」といいます）は、当方が提供するアプリケーション「SavePoint」（以下「本アプリ」といいます）における、ユーザーの個人情報の取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます）を定めます。

1. 収集する情報

本アプリのご利用にあたり、当方は以下の情報を取得します。

  • アカウント情報：メールアドレス、パスワード（暗号化して保存されます）。Sign in with AppleまたはGoogleでのサインインをご利用の場合は、各社から提供される識別子およびメールアドレス（Appleの場合は提供に同意いただいた場合のみ）
  • プロフィール情報：ユーザー名、表示名、公開範囲の設定（後述の「他ユーザーへの公開について」参照）
  • 生年月：成人向け作品の表示可否を判定するため、初回利用時に入力いただきます
  • ユーザー生成コンテンツ：本アプリ上で記録したゲームの評価・レビュー本文・ステータス（遊んだ／プレイ中／遊びたい）
  • つながり機能に関する情報：フォロー関係、ブロック関係、通報の内容（通報理由・詳細）
  • 閲覧履歴：記録・プロフィールの閲覧数を分析する機能（サブスク特典）のため、誰がいつどの記録・プロフィールを閲覧したかをサーバーに記録します。ご本人以外には、閲覧した人物ではなく件数のみが表示されます
  • プッシュ通知用の情報：プッシュ通知を有効にしている場合、端末を識別するためのデバイストークンと、端末で利用中のアプリのバージョン（アップデートのお知らせを、まだ更新していない端末にのみ送るために使用します）
  • Steam連携に関する情報（ご利用の場合のみ）：Steamライブラリの取り込み機能をご利用になった場合、ご入力いただいたSteamのプロフィールURL（またはカスタムURLの名前）をもとに、そのプロフィールで公開されている所有ゲームの一覧とプレイ時間を、Valve Corporationが提供するSteam Web APIから取得します。取得した一覧は、取り込み内容の確認と記録の作成のためだけに使用し、当方のサーバーには保存しません。ご確認のうえ取り込みを確定した記録（ゲームと状態）のみが、他の記録と同様に保存されます
  • 購入・サブスクリプション情報：有料プランをご利用の場合、購入状況・サブスクリプションの状態（後述のRevenueCatを通じて管理されます）
  • 利用状況に関する技術情報：本アプリの操作状況（画面遷移、検索キーワード等）、エラーログ、クラッシュ情報等
  • 広告配信に関する情報：本アプリは広告表示のため、後述のGoogle Mobile Ads（AdMob）を利用しています。広告配信にあたり、広告識別子・デバイス情報・おおよその位置情報（国／地域レベル）等がGoogleに送信される場合があります。詳細は下記「4. 第三者サービスの利用」および「5. 広告について」をご確認ください。

本アプリは、位置情報・連絡先へのアクセスは行いません。プロフィール画像を設定する際に限り、ユーザーが操作したときにカメラまたは写真の選択機能を利用します（撮影・選択した画像はプロフィール画像として保存されます）。

2. 情報の利用目的

取得した情報は、以下の目的でのみ利用します。

  • アカウントの作成・認証、ログイン状態の維持
  • ユーザーが投稿した記録・評価・レビューの保存および表示
  • フォロー・ブロック・通報等、ユーザー間の「つながり」機能の提供
  • 通報を受けた場合の内容確認および必要な対応（利用規約に違反するアカウント・投稿への対処等）
  • Steamライブラリの取り込み機能の提供（ユーザーが操作したときのみ）
  • プッシュ通知の配信（ご自身が有効にした種別のみ。設定画面からいつでも変更できます）
  • 本アプリの不具合調査・品質改善
  • 法令に基づく対応が必要な場合の対応

3. 他ユーザーへの公開について

本アプリには、他のユーザーをフォローし、フォロー中のユーザーが記録した作品を閲覧できる「つながり」機能と、フォロー関係を問わず全ユーザーのレビューを閲覧できる「みんなのレビュー」機能があります。

  • プロフィールの公開範囲は、初期状態では「非公開」です。ユーザー自身が設定画面で変更しない限り、他のユーザーに記録が表示されることはありません。公開範囲は「非公開」「相互フォローのみ公開」「全公開」の3段階から選べ、いつでも変更できます。
  • 記録（レビュー）は1件ごとに「公開する／しない」を選べます。「公開する」に設定し、かつプロフィールの公開範囲の条件（相互フォロー、または全公開）を満たした相手にのみ表示されます。
  • フォロー中のユーザーに表示される情報：作品名・ステータス（遊んだ／プレイ中／遊びたい）に加えて、評価（星の数）・レビュー本文・ネタバレフラグ・クリア状況・クリア時間も表示されます。積みゲーの優先度は表示されません。
  • 「みんなのレビュー」機能：プロフィールの公開範囲を「全公開」にしている場合、あなたが「遊んだ」として公開した評価・レビュー本文（クリア状況・クリア時間・ネタバレフラグを含む）は、フォロー関係を問わずアプリの全ユーザーに公開されます。ユーザー名・表示名・アバター画像をあわせて表示するかどうかは設定画面の「『みんなのレビュー』に身元を表示する」で選択でき、初期状態はオンです。オフにした場合、投稿者があなたであることは表示されませんが、レビューの内容自体は引き続き全ユーザーに公開されます。
  • 公開範囲・身元表示の設定はいつでも変更でき、非公開に戻した場合は以降新たに表示されなくなります。ただし、公開されていた間に他のユーザーが内容を閲覧・保存していた場合、その除去を当方が保証することはできません。
  • あなたが投稿したユーザー名・表示名は、ユーザー検索機能を通じて他のユーザーから見つけられる場合があります。
  • ユーザーをブロックすると、フォロー関係が解消され、以後お互いにフォローできなくなります。ブロックした事実やブロック一覧は、ブロックした本人以外には公開されません。
  • 通報の内容（通報理由・詳細、通報者・被通報者の情報）は、当方（運営）のみが確認でき、モデレーション対応の目的以外には利用しません。

4. 第三者サービスの利用

本アプリは、以下の第三者サービスを利用しています。それぞれのサービスは、各社のプライバシーポリシー・利用規約に基づきデータを取り扱います。

サービス 用途 送信される情報
Supabase 認証・データベース・サーバー機能 アカウント情報、投稿内容
Apple（Sign in with Apple） ログイン認証 Appleが発行する識別子、（同意時）メールアドレス
Google（Googleでサインイン） ログイン認証 Googleが発行する識別子、メールアドレス
IGDB / Twitch（Twitch Interactive, Inc.） ゲーム情報（タイトル・画像・概要等）の取得 検索キーワード（ユーザーの個人情報は送信されません）
Steam Web API（Valve Corporation） Steamライブラリの取り込み（ユーザーが操作したときのみ） ご入力いただいたSteamのプロフィールURLまたはカスタムURLの名前。取得した所有ゲーム一覧には、ValveのSteam Web API利用規約が適用されます
Google Cloud Translation API ゲーム概要文の日本語自動翻訳 ゲームの概要文（英語）のみ。ユーザーの個人情報は送信されません
Google Mobile Ads（AdMob） アプリ内広告の配信 広告識別子、デバイス情報、おおよその位置情報（国／地域レベル）等。詳細は下記「5. 広告について」参照
Firebase Analytics（Google） アプリの利用状況分析 画面遷移・検索キーワード・記録作成等の操作イベント（匿名化された利用統計として）
Firebase Crashlytics（Google） 不具合の検出・調査 クラッシュ・エラー情報、発生時の端末情報
Firebase Cloud Messaging（Google） プッシュ通知の配信 プッシュ通知用のデバイストークン
RevenueCat サブスクリプション・購入管理 購入情報、サブスクリプションの状態、アプリ内で発行されるユーザーID
YouTube API Services（Google） ゲームトレーラー動画のアプリ内再生 動画再生時に端末情報・IPアドレス等がGoogleに送信される場合があります。本アプリはYouTube API Servicesを利用しており、これに伴いYouTubeの利用規約およびGoogleのプライバシーポリシーが適用されます

5. 広告について

本アプリでは、Google AdMob（Google Mobile Ads SDK）を利用してアプリ内にバナー広告を表示しています。

  • 広告の配信にあたり、Googleおよびその広告パートナーが、広告識別子（Android Advertising ID / IDFA等）、デバイス情報、Cookie、おおよその位置情報等を取得・利用する場合があります。これらの情報の取り扱いについては、Googleのプライバシーポリシーをご確認ください。
  • EEA（欧州経済領域）・英国にお住まいのユーザーには、Googleの定めるユーザーメッセージングプラットフォーム（UMP）を通じて、広告配信に関する同意確認画面が表示される場合があります。
  • お使いの端末の設定（Androidの「広告」設定、iOSの「トラッキング」設定等）から、パーソナライズ広告の無効化やトラッキングの許可・拒否を選択いただけます。

6. 情報の第三者提供

法令に基づく場合を除き、取得した個人情報を、外部の事業者等の第三者に本人の同意なく提供することはありません。なお、本項でいう「第三者提供」は、当方が個人情報を外部事業者に渡すことを指すものであり、上記第3項に基づきユーザー自身の公開範囲設定に応じて他のユーザーに記録が表示されること、および上記第5項の広告配信に伴う情報の送信は含まれません。

7. 情報の保管・削除

  • ユーザー情報は、上記第4項に記載のサービス（主にSupabase、データセンターは提供国外を含みます）に保管されます。
  • アカウントの削除、および保有する個人情報の開示・訂正・削除をご希望の場合は、下記お問い合わせ先までご連絡ください。合理的な期間内に対応いたします。
  • Steamライブラリの取り込みで取得した所有ゲームの一覧は保存しません。取り込みを確定した記録のみが、他の記録と同様に保管されます。
  • 通報データは、モデレーション対応・不正利用防止の目的で、対応完了後も一定期間保管する場合があります。

8. お子様の利用について

本アプリは、原則として13歳未満の方の利用を想定していません。

9. 本ポリシーの変更

本ポリシーの内容は、必要に応じて予告なく変更されることがあります。重要な変更がある場合は、本アプリ内または本ページにてお知らせします。
