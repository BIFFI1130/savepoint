## 1. 収集する情報

本アプリのご利用にあたり、当方は以下の情報を取得します。

- **アカウント情報**：メールアドレス、パスワード（暗号化して保存されます）。Sign in with Appleをご利用の場合は、Appleから提供される識別子および（提供に同意いただいた場合）メールアドレス
- **ユーザー生成コンテンツ**：本アプリ上で記録したゲームの評価・レビュー本文・ステータス（遊んだ／遊びたい）
- **利用状況に関する技術情報**：本アプリの動作に必要な範囲でのエラーログ等（第三者へ広告目的等で提供することはありません）

本アプリは、位置情報・連絡先・写真・カメラ等へのアクセスは行いません。

## 2. 情報の利用目的

取得した情報は、以下の目的でのみ利用します。

- アカウントの作成・認証、ログイン状態の維持
- ユーザーが投稿した記録・評価・レビューの保存および表示
- 本アプリの不具合調査・品質改善
- 法令に基づく対応が必要な場合の対応

## 3. 第三者サービスの利用

本アプリは、以下の第三者サービスを利用しています。それぞれのサービスは、各社のプライバシーポリシー・利用規約に基づきデータを取り扱います。

| サービス | 用途 | 送信される情報 |
|---|---|---|
| Supabase | 認証・データベース・サーバー機能 | アカウント情報、投稿内容 |
| Apple（Sign in with Apple） | ログイン認証 | Appleが発行する識別子、（同意時）メールアドレス |
| IGDB / Twitch（Twitch Interactive, Inc.） | ゲーム情報（タイトル・画像・概要等）の取得 | 検索キーワード（ユーザーの個人情報は送信されません） |
| MyMemory Translation API | ゲーム概要文の日本語自動翻訳 | ゲームの概要文（英語）のみ。ユーザーの個人情報は送信されません |

## 4. 情報の第三者提供

法令に基づく場合を除き、取得した個人情報を本人の同意なく第三者に提供することはありません。

## 5. 情報の保管・削除

- ユーザー情報は、上記第3項に記載のサービス（主にSupabase、データセンターは提供国外を含みます）に保管されます。
- アカウントの削除、および保有する個人情報の開示・訂正・削除をご希望の場合は、下記お問い合わせ先までご連絡ください。合理的な期間内に対応いたします。
