SavePoint

遊んだゲームを記録・評価・レビューできる、あなただけのゲーム履歴帳。

アプリ概要

SavePointは、これまで遊んだゲーム・これから遊びたいゲームを記録し、評価やレビューを残せるiOS/Androidアプリです。主な機能は次のとおりです。

  • ゲームの検索・詳細閲覧（発売日・対応ハード・ジャンル・平均クリア時間などの情報表示）
  • 「遊んだ／遊びたい」ステータスと星評価・レビュー（ネタバレタグ付き）の記録
  • テーマ別コレクション、月間・年間まとめ、実績（バッジ）、ゲーム人生タイムライン
  • ユーザー間のフォロー・お気に入り（推しゲー）共有機能（公開範囲は記録ごとに設定可能、初期状態は非公開）
  • 新作・注目作の発売日カレンダー

技術構成・外部APIの利用状況

本アプリは以下の技術・外部サービスを利用して構築されています。

役割利用サービス・技術用途
フロントエンドFlutter（Dart） / Riverpod / go_routeriOS・Android向けアプリ本体
バックエンドSupabase（PostgreSQL / Auth / Edge Functions）認証、データベース、サーバーサイド処理
ゲームデータIGDB（Twitch Developer APIのOAuth経由）ゲームのタイトル・カバー画像・発売日・ジャンル・対応ハード・クリア時間等の取得。サーバー側のEdge Function（igdb-proxy）を経由してのみアクセスし、APIキーはクライアントに一切渡していません
翻訳Google Cloud Translation APIゲーム概要文（英語）の日本語自動翻訳。翻訳結果はデータベースにキャッシュし、同じ作品への再翻訳リクエストを発生させない設計です
認証Sign in with Apple / メール・パスワードログイン
クラッシュレポートFirebase Crashlyticsアプリの不具合調査・品質改善
CI/CDCodemagicビルド・配信の自動化

ゲームデータの提供元であるIGDBへの帰属表示は、アプリ内の該当画面すべてに表示しています。データ提供元: IGDB.com
