# SavePoint 1.0.6 (build 43) パッチノート

## このバージョンの新機能（App Store Connect用）

```
・アプリを起動するとクラッシュしてしまう不具合を修正しました
```

## 内訳

- 「発売が近い遊びたいゲーム」がない状態でアプリを起動すると、ホーム画面ウィジェット用データの書き込みで実機のみネイティブ例外が発生し、起動直後にクラッシュしていた不具合を修正（`home_widget`の`saveWidgetData`にnullを渡すとFlutterが`NSNull`として渡し、App Group共有UserDefaultsのプロパティリスト検証に失敗するため）。「値なし」は空文字で保存し、iOS/Androidのウィジェット側で空文字をnull相当として扱う
- シミュレータでは検証が緩く再現しないため、実機（iPhone 17）のクラッシュログで原因を特定
- 緊急度の高い不具合修正のため、優先審査を申請
