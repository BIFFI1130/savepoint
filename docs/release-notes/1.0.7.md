# SavePoint 1.0.7 (build 45) パッチノート

## このバージョンの新機能（App Store Connect用）

```
・SNSなどでシェアした画像・リンクから、SavePointをインストールできるようにしました
・プロフィールの共有リンクを、LINEやXなどでもタップして開ける形式に変更しました
・アプリの対応言語を日本語として正しく表示するよう修正しました
・その他細かな改善
```

## 内訳

- シェア文（月間・年間まとめ／実績／プレイ傾向診断／ゲーム）にハッシュタグとランディングページURLを付与
- プロフィール共有リンクを`savepoint://`から、httpsの中継ページ（`docs/u/`）経由に変更（QR・コピー・共有すべて）
- Info.plistに`CFBundleLocalizations`（ja）を宣言。App Storeの対応言語表示が「English」のみだった点と、システムダイアログが英語になる点を解消
- ストア掲載：名前・サブタイトル・キーワードを検索に強い内容へ変更（アプリ本体のコード変更なし）
