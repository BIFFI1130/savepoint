# SavePoint 1.0.3 (build 40) パッチノート

## このバージョンの新機能（App Store Connect用）

```
・星評価を0.1刻みで細かく入力できるようにしました
・プロフィール編集画面の保存ボタンを、常に画面下部に表示されるようにしました
・通知設定・プロフィール編集画面のレイアウトを見直し、読みやすくしました
・プロフィールの保存に関する不具合を修正しました
```
