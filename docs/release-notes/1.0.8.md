# SavePoint 1.0.8 (build 46) パッチノート

## このバージョンの新機能（App Store Connect用）

```
・「積みゲー消化シミュレーター」を追加しました。「遊びたい」に積んだゲームのクリア時間から、消化にかかる期間を計算できます（マイログの「積みゲー」から）
・Steamで持っているゲームを、まとめて記録に取り込めるようになりました（設定 →「Steamから取り込む」）
・「あなたへのおすすめ」が、高評価の作品に近いゲームを優先して表示されるようになりました
・まとめのシェア画像に、ベストゲームとQRコードを追加しました
・「遊びたい」に入れた作品の発売日が決まった・変更されたときに、通知でお知らせします（通知設定でオフにできます）
・新しいバージョンが公開されたときに、お知らせするようになりました
・記録がまだない方向けに、はじめの一歩を案内するカードを追加しました
・その他細かな改善
```

## 内訳

- 積みゲー消化シミュレーター（`/backlog-estimate`）、QR付きシェア画像
- Steam取り込み（`/steam-import`、steam-import Edge Function）。既定は非公開、既存の記録は上書きしない
- おすすめを好みの強さで重み付け（高評価に近い作品・複数の作品から挙がる作品を優先）
- 発売日変更通知（notify-release-changes）、アップデートのお知らせ（アプリ内ダイアログ＋notify-app-update）
- 設定の通知画面に「発売日の変更通知」「アップデートのお知らせ」を追加
- Android: 通知チャンネルを種別ごとに作成（新フォロワー/いいね/新着レビュー/週間ダイジェスト/発売日の変更/アップデート）
- 記録が空のホーム・マイログに案内カード
- プライバシーポリシーを更新（Steam連携・Googleサインイン・通知のアプリ版・カメラ利用）
