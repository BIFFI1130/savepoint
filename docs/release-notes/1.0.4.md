# SavePoint 1.0.4 (build 41) パッチノート

## このバージョンの新機能（App Store Connect用）

```
・Googleアカウントでサインインできない不具合を修正しました
```

## 内訳

- ローカルビルドへの移行時に、Googleサインインに必要なクライアントID（`GOOGLE_WEB_CLIENT_ID` / `GOOGLE_IOS_CLIENT_ID`）が`env/prod.json`に設定されておらず、Googleサインインが完全に機能しなくなっていた不具合を修正
- 緊急度の高い不具合修正のため、build 41としてリリース
