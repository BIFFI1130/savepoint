App Store Connect / Google Play Console に入力する文言のドラフト。文字数制限は各ストアの
入力欄で自動的にチェックされるため、ここでは目安として記載する。

```
SavePoint - ゲーム記録
```

## サブタイトル（App Store, 30文字以内）

```
遊んだゲームを記録・評価・レビュー
```

## 簡単な説明（Google Play, 80文字以内）

```
遊んだ・遊びたいゲームを記録し、評価やレビューを残せる、あなただけのゲーム履歴帳。
```

## 詳しい説明（App Store 4000文字 / Google Play 4000文字、共通で使える文面）

```
SavePointは、あなたが歩んできた「ゲーム人生」を記録するアプリです。

■ 遊んだゲーム・遊びたいゲームを記録
IGDB（世界最大級のゲームデータベース）から作品を検索し、「遊んだ」「遊びたい」の
ステータス・星評価・レビューを記録できます。ネタバレを含むレビューには「ネタバレあり」
タグを付けられるので、安心して感想を書き残せます。

■ コレクションで整理
「積みゲー」「神ゲー殿堂」など、テーマ別に自由にコレクションを作って作品を整理できます。

■ 月間・年間まとめ
記録した本数、平均評価、ジャンルの傾向などを月ごと・年ごとに振り返れます。

■ 実績・バッジ
記録数や連続記録月数などに応じて実績が解放され、記録を続けるモチベーションになります。

■ ゲーム人生タイムライン
これまで記録してきた作品を時系列で振り返る、あなただけのゲーム年表を作れます。

■ 発売日カレンダー
新作・注目作の発売日をカレンダーやリストで確認できます。

■ つながり機能（任意）
プロフィールを公開すると、フォローしているユーザーの「遊んだ／遊びたい」ステータスを
閲覧できます。公開範囲は記録ごとに細かく設定でき、初期状態はすべて非公開です。

ゲーム情報の提供: IGDB (https://www.igdb.com)
```

## 年齢レーティング（回答方針）

App Store Connect / Google Play Console（IARC）の質問票はストア側のフォームで直接回答する必要があるため、代わりに埋めることはできない。回答時の考え方は以下の通り。

- **ユーザー生成コンテンツ（レビュー・表示名等）**: あり、と回答する。投稿前の自動検閲はなく、[通報機能](../README.md)による事後対応のみのため。
- **性的・扇情的なコンテンツ**: 「軽度」または相当する選択肢を選ぶ。検索・一覧画面に「成人向け作品を表示する」チェックボックス（デフォルトOFF）があり、有効にするとIGDB上でErotic（成人向け）テーマに分類された作品の名称・カバー画像・概要が表示されうるため。18歳未満と判定されるユーザー（生年月を入力済みの場合）には、このチェックボックス自体を表示しない制御を実装済み。
- **暴力表現**: アプリ自体はゲームの記録・レビューアプリであり、暴力的な描写を直接含まない。ただし表示される作品名・カバー画像・概要はIGDBデータそのままであり、暴力的な内容を含むゲーム（例: アクション・ホラー作品）の情報が表示されうる点は「軽度の暴力への言及」程度として申告する。
- **ギャンブル・賭博**: なし。
- **ユーザー間のコミュニケーション**: あり（フォロー・ステータス閲覧のみ、DM等の直接メッセージ機能はなし）。ブロック・通報機能を実装済み。
- **位置情報・連絡先等へのアクセス**: なし。

結果として、App Storeは概ね「12+」〜「17+」、Google Playは「ティーン」〜「成熟(Mature 17+)」相当になる可能性が高い。最終的な等級はストア側の質問票の回答結果に従う。
